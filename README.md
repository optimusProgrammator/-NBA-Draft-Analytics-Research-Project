# 📊 Overview

The **NBA Draft Analytics Research Project** is a data-driven analysis exploring the relationship between NBA draft position and long-term player success.

Using historical NBA draft data, statistical analysis, and data visualization, this project investigates how accurately draft position predicts career impact and identifies players who exceeded or fell below expectations.

The project aims to answer questions such as:

- Does being selected earlier in the NBA Draft guarantee greater career success?
- Which draft selections provided the most value relative to expectations?
- How can player impact be measured using statistical indicators?
- What patterns exist across different NBA draft classes?

By combining programming, statistics, and basketball analysis, this project demonstrates how data science can be applied to sports research.

# ⚠️ Disclaimers & Limitations

## Data Limitations

This project uses publicly available NBA draft and player performance datasets.

Although efforts are made to maintain accuracy, datasets may contain:

- Missing player information
- Incomplete career statistics
- Differences in statistical tracking across NBA eras
- Potential errors from external sources

The analysis should be viewed as an exploratory research project rather than an official NBA evaluation system.

---

## Impact Score Limitations

The **Impact Score** is a custom analytical metric created for this project.

It is not an official NBA statistic and should not be interpreted as a definitive measurement of player ability.

Basketball performance is influenced by many factors that cannot be fully represented numerically, including:

- Team systems
- Coaching
- Injuries
- Player roles
- Leadership
- Defensive impact
- Playoff performance
- Competition level

The metric is intended to identify trends and support analysis, not replace professional scouting.

---

## Statistical Limitations

Statistical relationships do not always represent direct cause-and-effect relationships.

For example:

A high draft selection may correlate with greater success, but other factors contribute to career outcomes, including:

- Development opportunities
- Team decisions
- Player health
- Organizational support

Results should be interpreted as patterns within the dataset rather than guaranteed predictions.

---

## Research Scope

This project focuses primarily on quantitative basketball analysis.

Factors outside the scope of this project include:
